# Project guidance

## Product scope

- Build a simple, interactive English-to-German learning app for learners at A1 to B1.
- Focus on quizzes and practical *Eselsbrücken* tied to situations expats encounter.
- Prefer useful, contextual language over arbitrary phrase lists or disconnected example sentences.
- Keep the app lightweight and easy to share; plain HTML, CSS, and JavaScript are the intended starting point.
- Treat Google Drive hosting as a goal to verify, not an established capability. Shared HTML must actually run for friends without a development setup.

## Learning content

- Make the situation and intended meaning clear to an English-speaking learner.
- Keep German examples natural and appropriate to their stated proficiency level.
- Explain memory aids in context, including when they help; do not present mnemonic tricks as grammar rules.
- Keep quiz prompts, accepted answers, and feedback aligned. Explain mistakes constructively.
